Exercise 1 – Basic Output
Source: Deitel & Deitel, C How to Program, 9th Edition, Chapter 2, Exercise 2.9a.
What the program does: Prints a simple friendly greeting ("Have a nice day.") directly to the terminal screen.
Concepts used: printf, standard I/O library (<stdio.h>), main function structure.
How it works: Includes standard input/output headers, enters main(), and runs a single printf call to display the message.

Exercise 2 – Input, Process, Output
Source: Deitel & Deitel, C How to Program, 9th Edition, Chapter 2, Exercise 2.16.
What the program does: Asks the user for two integers and outputs their sum, difference, product, quotient, and remainder.
Concepts used: scanf, printf, integer variables, basic arithmetic operators (+, -, *, /, %).
How it works: Prompts for two numbers, reads them with scanf, performs standard arithmetic, and prints out each calculated result.

Exercise 3 – Decisions
Source: Deitel & Deitel, C How to Program, 9th Edition, Chapter 2, Exercise 2.2.
What the program does: Evaluates relational conditions on users values to make simple decision choices.
Concepts used: if statements, relational operators (==, !=, <, >), conditional branchin.
How it works: Accepts input values, tests conditions through if statements, and prints specific messages based on which checks evaluate to true.

Exercise 4 – Basic Loop
Source: Deitel & Deitel, C How to Program, 9th Edition, Chapter 4, Exercise 4.11.
What the program does: Reads a sequence of numbers from the user and determines the smallest integer in the group.
Concepts used: for loop,variables, comparison logic, printf, scanf.
How it works: Asks how many numbers to expect, loops through that exact count to read each entry, keeps track of the lowest value seen, and prints it at the end.

Exercise 5 – Loop Calculation
Source: Deitel & Deitel, C How to Program, 9th Edition, Chapter 4, Exercise 4.13.
What the program does: Calculates and prints the total product of odd integers ranging from 1 to 15.
Concepts used: for loop, variables, operators .
How it works: Starts a product variable at 1, loops through odd numbers by stepping 2 counts each pass, multiplies each into the total, and prints the final output.

Exercise 6 – Loop Input
Source: Deitel & Deitel, C How to Program, 9th Edition, Chapter 4, Exercise 4.11.
What the program does: Prompts the user repeatedly within a loop to collect and process a set of inputs.
Concepts used: for loop,  input with scanf.
How it works: Sets up a count-controlled loop, asks for a value on every iteration, processes each entry, and wraps up once the total count is reached.

Exercise 7 – Loop Decision
Source: Deitel & Deitel, C How to Program, 9th Edition, Chapter 3, Exercise 3.20.
What the program does: Continuously calculates earnings or payments for multiple entries until the user types -1 to quit.
Concepts used: while loop, if...else decision logic, floating-point variables.
How it works: Prompts for input inside a while loop, breaks immediately if the sentinel value -1 is entered, and otherwise calculates and prints results for each pass.

Exercise 8 – Interactive Program
Source: Deitel & Deitel, C How to Program, 9th Edition, Chapter 4, Exercise 4.19.
What the program does: Runs an interactive product menu that calculates total retail sales based on item numbers and quantities.
Concepts used: switch statement, while loop, switch function control, running totals.
How it works: Repeatedly prompts for item pairs, routes each product ID through a switch block to add costs, and prints the overall summary when entry ends.
